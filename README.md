# Team Danmark – navigationsprototype

Wireframe-prototype af det nye teamdanmark.dk. Hele prototypen ligger i én HTML-fil, `wireframe/index.html`, som kan åbnes direkte i en browser.

Prototypen indeholder forsiden, de fire sektionsforsider og niveau 2-sider for Træning & præstation, Talent & udvikling og Om os. Indholdet bygger på det nuværende teamdanmark.dk og Team Danmarks egne udgivelser. Grå bokse er pladsholdere for billeder.
